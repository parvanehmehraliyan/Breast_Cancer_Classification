# Breast Cancer Classification

## Overview
This project uses a Random Forest machine learning model to classify breast cancer data.

## Dataset
The project uses the Breast Cancer Wisconsin dataset available in scikit-learn.

## Model
- Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Technologies
- Python
- scikit-learn

## How to Run
1. Install Python.
2. Install scikit-learn:
   `pip install scikit-learn`
3. Run the project:
   `python main.py`

## Disclaimer
This project is for educational purposes only and is not intended for medical diagnosis.
